# 용산 배드민턴 접수 알림

용산구 시설관리공단 강좌 목록을 5분마다 확인하고, 번호 1·2 중 하나의 신청 버튼이 `접수 종료`가 아니면 GitHub 이슈 알림을 한 번 생성합니다.

## 감시 조건

- 대상 URL: 월·수·금 배드민턴 목록
- 대상 행: `[data-title="번호"]`의 텍스트가 `1` 또는 `2`
- 신청 버튼: 같은 `tr` 안의 `[data-title="신청"] a`
- 알림 조건: 신청 버튼 텍스트에서 공백을 제거한 값이 `접수종료`가 아님
- 안전장치: 1·2번 행이나 신청 링크를 못 찾으면 오류로 종료하고 알림하지 않음

## 설치

1. GitHub에서 새 **공개 저장소**를 만듭니다. 이 코드에는 개인정보나 비밀값이 없고, 공개 저장소의 표준 GitHub Actions는 무료입니다. 비공개 저장소에서 5분 주기로 돌리면 무료 실행 시간을 빠르게 소진할 수 있습니다.
2. 이 폴더의 파일을 폴더 구조 그대로 업로드합니다. 특히 `.github/workflows/monitor.yml`이 빠지면 안 됩니다.
3. 저장소의 `Actions` 탭에서 `배드민턴 접수 모니터링`을 열고 `Run workflow`로 한 번 실행합니다.
4. GitHub 앱 또는 GitHub 이메일 알림을 켭니다. 접수가 열리면 본인에게 할당된 `[배드민턴 알림] 접수 가능` 이슈가 생성됩니다.

GitHub의 예약 실행은 정확히 정각을 보장하지 않으므로 혼잡할 때 몇 분 지연될 수 있습니다.

## 알림 재설정

한 번 알림이 생성되면 같은 열린 이슈가 있는 동안 중복 알림을 만들지 않습니다. 다음 모집을 다시 감시하려면 기존 `[배드민턴 알림] 접수 가능` 이슈를 **닫으면** 됩니다.

## 로컬 테스트

```bash
python -m unittest discover -s tests -v
python monitor.py
```

현재 대상 사이트는 일부 환경에서 인증서 체인이 완전하지 않습니다. 코드는 정상 인증서 검증을 먼저 시도한 뒤, 인증서 오류일 때만 읽기 전용 GET 요청을 검증 없이 한 번 재시도합니다.
